# Simon Kostovcik — Portfolio

Personal portfolio website (Czech) built with semantic HTML, CSS and vanilla JavaScript.

## Included
- `index.html` — page content
- `style.css` — responsive layout and styling
- `script.js` — accessible mobile menu

## Deployment
Create a public GitHub repository named `portfolio`, upload the three files to its root, and enable **Settings → Pages → Deploy from a branch → main → /(root)**.

Expected URL: `https://simokostovcik-hash.github.io/portfolio/`

## Before contacting clients
- Replace the temporary GitHub contact link in the `#kontakt` section with your actual business email or another reliable contact channel.
- Verify all project links and mobile layout.
- The linked projects are clearly labelled as fictional/demo portfolio work.
- No fake testimonials or client claims are used.

## Notes
Fonts are requested from Google Fonts with system fallbacks. No build tooling is required.
